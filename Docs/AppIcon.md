# App icon

Warm ivory background with a graphite open book and a small page turn. Generated using the built-in imagegen tool, then resized for iPhone and iPad.

## Generation prompt

Use case: logo-brand. Asset type: production iOS app icon for Simple Reader, a minimal native ebook reader. Create ONE square 1024 x 1024 icon image. Full bleed opaque solid warm ivory background #F5F2EB extending to all four square corners, no rounded outer mask. Center a single bold dark graphite #28332F open-book silhouette. Inspired by the simplicity and instantly legible book metaphor of Apple Books and Readest, with an original restrained design. Two solid gently curved pages separated by a narrow ivory central gutter; the right page has one subtle lifted page corner integrated into the silhouette. The book occupies about 60 percent of the canvas width and 46 percent height, optically centered. Flat vector-like geometry, precise smooth edges, quietly balanced generous negative space. Only two colors. No letters, words, watermark, borders, texture, gradients, shadows, 3D, decorations, stars, or mockup. Output only the actual square icon artwork.
