# Bundled reader fonts

Downloaded from the official upstream repositories on 2026-10-06. All binaries
are unmodified and licensed under SIL OFL 1.1. Full copyright and license texts
are bundled in `../Licenses/LXGWWenKai.txt` and `../Licenses/SourceSerif4.txt`.

Readium serves these files locally to EPUB web views using CSS font declarations.
The default stack is `Source Serif 4`, `LXGW WenKai`, `serif`: Source Serif covers
Western text and WenKai supplies CJK glyphs, including in mixed-language books.
WenKai uses its regular face with browser-synthesized emphasis. Source Serif
includes real bold, italic and bold italic faces in its Text optical size.
No network connection is needed while reading.
